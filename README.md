# gestor de tareas 📋

**descripcion:** esta es la primera version del gestor de tareas de python como dice el nombre sirve para gestionar tus tareas dandote las opciones de añadir tareas con el nombre que quieras, marcarlas como completadas y ver cuales tienes pendiente y cuales estan completadas

## funciones 🔧
- agregar tareas
- marcar pendientes
- ver pendientes
- ver completadas

## como ejecutar ⚙

para ejecutar se da a **ctrl+j** y en la terminal se escribe **python3 main.py**

## tecnolgia usada 💻

se uso solamente python
